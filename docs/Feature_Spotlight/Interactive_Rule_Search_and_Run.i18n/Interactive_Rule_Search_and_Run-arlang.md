# البحث عن القواعد التفاعلية وتشغيلها

تسلط هذه الأضواء الضوء على نظام البحث التفاعلي عن القواعد وتنفيذها، وربط الأوامر الصوتية، والتنقل المباشر، والتنفيذ الفوري.

                                           ## الميزات الأساسية
[1] ** البحث المباشر ثنائي الجزء (`fzf`):** يقوم الجزء الأيسر بتصفية ملفات القاعدة؛ يعرض الجزء الأيمن معاينة سياق السطر عبر `preview_rule.py`.
[2] ** عمليات التنفيذ الفورية (`Enter` / `Ctrl+R`):** تشغيل أمر الهدف المستخرج على الفور عبر `run_palette_command.py` في الخلفية.
[3] ** التحرير المباشر (`Ctrl+E`):** تشغيل المحرر (CudaText مع `@line`، Kate/VS Code مع `--line`) مباشرة على السطر المستهدف.
[4] **مفتاح التشغيل السريع للنافذة العائمة:** مرتبط بـ `Super+S` للحصول على سير عمل سريع ومتكامل لمساحة العمل على سطح المكتب.
[5] **مدعم بالأوامر الصوتية:** تعمل العديد من الأوامر الصوتية على تكوين أنماط البحث مسبقًا في `search_rules.sh` لإجراء عمليات بحث سريعة ومستهدفة.

                             ## دعم عبر الأنظمة الأساسية
- **Linux Bash (`run_rule.sh` / `search_rules.sh`):** تنفيذ كامل المواصفات مع تتبع السجل وعمليات الحافظة (`Ctrl+X` / `Ctrl+A`).
- **Windows PowerShell (`search_rules.ps1`):** أداة مصاحبة توفر إمكانات بحث طرفية خفيفة الوزن.
