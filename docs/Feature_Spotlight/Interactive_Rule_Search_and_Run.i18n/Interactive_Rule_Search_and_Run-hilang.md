# इंटरएक्टिव नियम खोजें और चलाएँ

यह स्पॉटलाइट इंटरैक्टिव नियम-खोज और निष्पादन प्रणाली, वोकल कमांड, लाइव नेविगेशन और त्वरित निष्पादन को जोड़ने पर प्रकाश डालता है।

## मुख्य विशेषताएं
[1] **डुअल-पेन लाइव सर्च (`fzf`):** बायां फलक नियम फ़ाइलों को फ़िल्टर करता है; दायां फलक `preview_rule.py` के माध्यम से लाइन-संदर्भ पूर्वावलोकन प्रदर्शित करता है।
[2] **त्वरित निष्पादन (`एंटर` / `Ctrl+R`):** पृष्ठभूमि में `run_palette_command.py` के माध्यम से निकाले गए लक्ष्य कमांड को तुरंत चलाता है।
[3] **डायरेक्ट एडिटिंग (`Ctrl+E`):** एडिटर (`@line` के साथ CudaText, `--line` के साथ केट/वीएस कोड) को सीधे लक्षित लाइन पर लॉन्च करता है।
[4] **फ़्लोटिंग विंडो हॉटकी:** तेज़, डेस्कटॉप-एकीकृत कार्यक्षेत्र वर्कफ़्लो के लिए `सुपर+एस` से बंधा हुआ।
[5] **वॉयस-कमांड संचालित:** कई वॉयस कमांड तेज, लक्षित लुकअप के लिए `search_rules.sh` में खोज पैटर्न को पूर्व-कॉन्फ़िगर करते हैं।

## क्रॉस-प्लेटफ़ॉर्म समर्थन
- **लिनक्स बैश (`run_rule.sh` / `search_rules.sh`):** इतिहास ट्रैकिंग और क्लिपबोर्ड संचालन (`Ctrl+X` / `Ctrl+A`) के साथ पूर्ण-विशेषीकृत कार्यान्वयन।
- **Windows PowerShell (`search_rules.ps1`):** सहयोगी उपकरण हल्के टर्मिनल खोज क्षमताएं प्रदान करता है।
