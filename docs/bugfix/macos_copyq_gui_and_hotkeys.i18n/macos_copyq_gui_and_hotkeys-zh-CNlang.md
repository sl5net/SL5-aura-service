# CopyQ macOS 故障排除：不可见的 GUI 和手动热键配置

本指南解决了 macOS（特别是 Apple Silicon M 系列设备）上遇到的常见问题，其中 CopyQ 图形界面 (GUI) 不出现，或者需要在不访问 GUI 的情况下重新分配全局快捷键（例如 F10）。

---

## 1. 不可见 GUI 故障排除

在 macOS 上，CopyQ 可以在后台正常运行，同时保持视觉隐藏，主要原因有两个：
- **离屏窗口坐标**：分辨率更改或断开外部监视器后，CopyQ 可能会保留可见显示区域之外的坐标。
- **菜单栏凹口遮挡**：在带有摄像头凹口的 MacBook 机型上，当托盘已满时，macOS 会自动隐藏凹口后面多余的菜单栏图标。
