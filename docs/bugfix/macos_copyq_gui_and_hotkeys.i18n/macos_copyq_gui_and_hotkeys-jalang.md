# CopyQ macOS トラブルシューティング: 非表示の GUI と手動ホットキー設定

このガイドでは、CopyQ グラフィカル インターフェイス (GUI) が表示されない、または GUI にアクセスせずにグローバル ショートカット (F10 など) を再割り当てする必要がある、macOS (特に Apple Silicon M シリーズ デバイス) で発生する一般的な問題について説明します。

---

## 1. 非表示の GUI のトラブルシューティング

macOS では、CopyQ は、次の 2 つの主な理由により、視覚的には非表示のままで、バックグラウンドで適切に実行される場合があります。
- **オフスクリーン ウィンドウの座標**: 解像度の変更後、または外部モニターの接続解除後、CopyQ は表示可能な表示領域外の座標を保持する場合があります。
- **メニュー バーのノッチの障害**: カメラ ノッチのある MacBook モデルでは、トレイがいっぱいになると、macOS が余分なメニュー バー アイコンをノッチの後ろに自動的に隠します。

### 解決策: ジオメトリをリセットして表示を強制する

ターミナルで次のコマンドを実行して、オフスクリーン座標をクリアし、ウィンドウを最前面に表示します。

```bash
copyq config geometry ""
copyq show
```

それでもウィンドウが表示されない場合は、CLI を使用してウィンドウの状態を切り替えます。

```bash
copyq toggle
```

## 2. CudaText を使用してホットキーを手動で変更する

グローバル ショートカット (「F10」など) が別のアプリケーションによって要求またはインターセプトされた場合、CopyQ GUI を開かずに、CudaText を使用して設定ファイル内でショートカットを直接編集できます。

### ステップ 1: CopyQ プロセスを終了する

CopyQ は、終了時に変更が上書きされないように、構成ファイルを編集する前に停止する必要があります。

```bash
copyq exit
```

### ステップ 2: CudaText で設定を開く

macOS では、CopyQ コマンドのショートカットは「copyq-commands.ini」に保存されます。

CudaText でファイルを開きます。

```bash
cudatext "$HOME/Library/Application Support/copyq/copyq-commands.ini"
```

*注意: ファイルが「Application Support」に存在しない場合は、XDG フォールバックの場所を開きます。*

```bash
cudatext "$HOME/.config/copyq/copyq-commands.ini"
```

### ステップ 3: ショートカットを再割り当てする

1- CudaText で、「Cmd + F」を押して検索バーを開きます。
2- 「F10」または「GlobalShortcut=F10」を検索します。
3- `F10` を利用可能なショートカット (たとえば、`F9` または `Ctrl+F10` または `Meta+F10`) に置き換えます。
4- ファイルを保存し (`Cmd + S`)、CudaText を閉じます (`Cmd + Q`)。

### ステップ 4: CopyQ を再起動する

CopyQ を再度起動して、更新されたショートカット構成をロードします。

```bash
open -a CopyQ
```

新しいグローバル ショートカットがアクティブになります。
