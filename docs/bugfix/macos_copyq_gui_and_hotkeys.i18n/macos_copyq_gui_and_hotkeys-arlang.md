# استكشاف أخطاء CopyQ لنظام التشغيل MacOS وإصلاحها: واجهة المستخدم الرسومية غير المرئية وتكوين مفتاح التشغيل السريع اليدوي

يتناول هذا الدليل المشكلات الشائعة التي تواجهها أجهزة macOS (خاصة أجهزة Apple Silicon M-series) حيث لا تظهر واجهة CopyQ الرسومية (GUI)، أو تحتاج إلى إعادة تعيين الاختصارات العامة (مثل F10) دون الوصول إلى واجهة المستخدم الرسومية.

                                                                          ---

## 1. استكشاف أخطاء واجهة المستخدم الرسومية غير المرئية وإصلاحها

في نظام التشغيل macOS، قد يعمل CopyQ بشكل صحيح في الخلفية بينما يظل مخفيًا بصريًا لسببين رئيسيين:
- **إحداثيات النافذة خارج الشاشة**: بعد تغيير الدقة أو فصل شاشة خارجية، قد يحتفظ CopyQ بالإحداثيات خارج منطقة العرض المرئية.
- **عائق شريط القائمة**: في طرز MacBook المزودة بحز كاميرا، يقوم macOS تلقائيًا بإخفاء أيقونات شريط القائمة الزائدة خلف الحز عندما يكون الدرج ممتلئًا.

           ### الحل: إعادة ضبط الهندسة وعرض القوة

قم بتنفيذ الأوامر التالية في الوحدة الطرفية لمسح الإحداثيات الموجودة خارج الشاشة وإحضار النافذة إلى المقدمة:

```bash
copyq config geometry ""
copyq show
```

إذا لم تظهر النافذة بعد، قم بتبديل حالتها عبر سطر الأوامر:

```bash
copyq toggle
```

## 2. تغيير مفاتيح التشغيل السريع يدويًا باستخدام CudaText

عند المطالبة باختصار عام (مثل `F10`) أو اعتراضه بواسطة تطبيق آخر، يمكن تحرير الاختصار مباشرة في ملف التكوين باستخدام CudaText دون فتح واجهة المستخدم الرسومية CopyQ.

                              ### الخطوة 1: إنهاء عملية CopyQ

يجب إيقاف CopyQ قبل تحرير ملف التكوين لمنعه من الكتابة فوق تغييراتك عند الإنهاء:

```bash
copyq exit
```

                    ### الخطوة 2: افتح التكوين في CudaText

على نظام التشغيل macOS، يتم تخزين اختصارات أوامر CopyQ في "copyq-commands.ini".

                                           افتح الملف في CudaText:

```bash
cudatext "$HOME/Library/Application Support/copyq/copyq-commands.ini"
```

*ملاحظة: إذا لم يكن الملف موجودًا في "دعم التطبيقات"، فافتح موقع XDG الاحتياطي:*

```bash
cudatext "$HOME/.config/copyq/copyq-commands.ini"
```

                   ### الخطوة 3: إعادة تعيين الاختصار

   1- في CudaText، اضغط على `Cmd + F` لفتح شريط البحث.
                            2- ابحث عن `F10` أو `GlobalShortcut=F10`.
3- استبدل `F10` بالاختصار المتاح (على سبيل المثال، `F9` أو `Ctrl+F10` أو `Meta+F10`).
          4- احفظ الملف (`Cmd + S`) وأغلق CudaText (`Cmd + Q`).

                                  ### الخطوة 4: أعد تشغيل CopyQ

ابدأ تشغيل CopyQ مرة أخرى لتحميل تكوين الاختصار المحدث:

```bash
open -a CopyQ
```
