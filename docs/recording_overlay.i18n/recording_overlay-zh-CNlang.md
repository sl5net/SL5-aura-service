# 录制叠加（屏幕显示）

录音覆盖提供了听写状态的即时、跨平台视觉指示器。它独立于桌面通知守护程序和“请勿打扰”过滤器运行，直接在主屏幕上显示状态。

## 州

- **录音 (`🔴`)**：带有突出显示轮廓的鲜红圆圈（`#181818` 上的`#e62222`）表示正在录音。
- **闲置的**：
- `hidden`（默认）：窗口完全撤回，释放桌面空间以进行正常交互。
- “五边形”：在空闲模式下显示微妙的几何五边形徽章（“⬟”）。
