많은 검색 옵션 외에도 개발 환경에는 전체 텍스트 검색이 있을 수 있습니다. 다음을 사용할 수도 있습니다.

스크립트/search_rules/search_rules.sh

이를 통해 기존 맵이나 소스 코드 또는 문서에서 검색할 수 있습니다. 그런 다음 좋아하는 편집기에서 찾은 평화를 열거나 github에서 열거나... 필요에 따라 스크립트를 구성하세요.

MAPS_DIR은 위치 인수 또는 환경 변수를 통해 구성 가능합니다.

스크립트는 하드 코딩된 기본값을 유지하지만 재정의를 허용합니다.

- 우선순위: 1) 첫 번째 위치 매개변수($1), 2) 기존 MAPS_DIR 환경 변수,
3) 하드 코딩된 기본 "$SL5NET_AURA_PROJECT_ROOT/config/maps".
- 스크립트를 편집하지 않고도 CI, 로컬 재정의 및 테스트의 유연성이 향상됩니다.
- 경로가 유효하지 않은 경우 조기에 실패하도록 인용 및 디렉터리 존재 확인을 추가합니다.

사용 예:
- ./search_rules.sh는 기본값을 사용합니다.
- ./search_rules.sh ./docs는 제공된 경로를 사용합니다.
- MAPS_DIR=/env/maps ./search_rules.sh

이는 구성을 명시적으로 지정하면서 이전 버전과의 호환성을 유지합니다.

약간 더 적은 작업을 수행할 수 있는 Windows PC용 버전(이 폴더에)도 있습니다: search_rules.ps1
