多くの検索オプションに加えて、開発環境にはおそらく全文検索があります。以下を使用することもできます。

スクリプト/search_rules/search_rules.sh

これにより、既存のマップ、ソース コード、ドキュメント内を検索できます。そして、お気に入りのエディターで見つけたピースを開くか、github で開くか...必要に応じてスクリプトを構成してください。

MAPS_DIR は位置引数または環境変数を介して構成可能です

スクリプトはハードコードされたデフォルトを維持しますが、オーバーライドを許可します。

- 優先順位: 1) 最初の位置パラメータ ($1)、2) 既存の MAPS_DIR 環境変数、
3) ハードコーディングされたデフォルトの「$SL5NET_AURA_PROJECT_ROOT/config/maps」。
- スクリプトを編集せずに、CI、ローカル オーバーライド、テストの柔軟性が向上します。
- パスが無効な場合に早期に失敗するように、引用符とディレクトリの存在チェックを追加します。

使用例:
- ./search_rules.sh はデフォルトを使用します
- ./search_rules.sh ./docs は指定されたパスを使用します
- MAPS_DIR=/env/maps ./search_rules.sh

これにより、構成を明示的にしながら、下位互換性が維持されます。

もう少し機能が少ない Windows PC 用のバージョン (このフォルダー内) もあります: search_rules.ps1
