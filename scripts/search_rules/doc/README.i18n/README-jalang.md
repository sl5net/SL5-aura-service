# Alt+F と Alt+G

## **ロジック**

説明と **Alt+F** の類似性に基づいて、**Alt+G** のロジックは次のようになります。

### **1.フルテキスト → DITTO からの切り替え (`Alt+G`)**

- **アクション**：
- 現在の検索クエリ (`CURRENT_QUERY`) は `SAVED_QUERY` に保存されます。
- 検索フィールドは**クリア**されます。
- `DITTO_STATE` は `"1"` に設定されます。
- GUIのリロード

### **2.同上モード**

- **任意の入力 (キーストローク)**:
- DITTO モードは **自動的に終了します** (`DITTO_STATE="0"`)。
- GUIのリロード
- 検索フィールドは **空**のままです (`SAVED_QUERY` は復元されません)。

### **3. DITTO → フルテキストへの切り替え (再度「Alt+G」)**

- **アクション**：
- `DITTO_STATE` は `"0"` に設定されます。
- GUIのリロード
- `SAVED_QUERY` は **復元**されます。 (このステップは現時点では機能しません。'26 年 11 月 8 日 22:18 火)
