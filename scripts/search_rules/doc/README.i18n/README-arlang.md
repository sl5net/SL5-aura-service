# المنطق المطلوب

                                                             # Alt+F و Alt+G

                                                          ## **المنطق**

استنادًا إلى الوصف والقياس مع **Alt+F**، يجب أن يبدو منطق **Alt+G** كما يلي:

     ### **1. التبديل من النص الكامل → DITTO (`Alt+G`)**

                                                                - **فعل**:
- تم حفظ استعلام البحث الحالي (`CURRENT_QUERY`) في `SAVED_QUERY`.
                                            - حقل البحث ** مسح **.
                                    - تم ضبط `DITTO_STATE` على `"1"`.
         - إعادة تحميل واجهة المستخدم الرسومية

                                                 ### **2. في وضع DITTO**

                          - **عند أي إدخال (ضغطة مفتاح)**:
- تم الخروج من وضع DITTO ** تلقائيًا ** (`DITTO_STATE = "0"`).
         - إعادة تحميل واجهة المستخدم الرسومية
- يظل حقل البحث **فارغًا** (لا يمكن استعادة `SAVED_QUERY`).

### **3. التبديل من DITTO → نص كامل (`Alt+G` مرة أخرى)**

                                                                - **فعل**:
                                    - تم ضبط `DITTO_STATE` على `"0"`.
         - إعادة تحميل واجهة المستخدم الرسومية
                                 - `SAVED_QUERY` **تمت استعادته**.
