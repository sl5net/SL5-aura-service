# Alt+F 및 Alt+G

## **논리**

**Alt+F**에 대한 설명과 비유를 바탕으로 **Alt+G**의 논리는 다음과 같습니다.

### **1. 전체 텍스트 → DITTO(`Alt+G`)**에서 전환

- **행동**:
- 현재 검색어(`CURRENT_QUERY`)는 `SAVED_QUERY`에 저장됩니다.
- 검색 필드가 **삭제**됩니다.
- `DITTO_STATE`가 `"1"`로 설정되었습니다.
- GUI 다시 로드

### **2. DITTO 모드**

- **입력 시(키 입력)**:
- DITTO 모드는 **자동으로 종료됩니다**(`DITTO_STATE="0"`).
- GUI 다시 로드
- 검색 필드는 **비어 있습니다**(`SAVED_QUERY`가 복원되지 않음).

### **3. DITTO → 전체 텍스트에서 전환(다시 `Alt+G`)**

- **행동**:
- `DITTO_STATE`는 `"0"`으로 설정됩니다.
- GUI 다시 로드
- `SAVED_QUERY`가 **복원**되었습니다. (11.8.'26 22:18 Tue 현재 이 단계는 작동하지 않습니다)
