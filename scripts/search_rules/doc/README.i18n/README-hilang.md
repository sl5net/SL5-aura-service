# Alt+F और Alt+G

## **तर्क**

विवरण और **Alt+F** के सादृश्य के आधार पर, **Alt+G** के लिए तर्क इस तरह दिखना चाहिए:

### **1. पूर्ण-पाठ से स्विच करना → DITTO (`Alt+G`)**

- **कार्रवाई**:
- वर्तमान खोज क्वेरी (`CURRENT_QUERY`) को `SAVED_QUERY` में सहेजा गया है।
- खोज फ़ील्ड **साफ़** कर दी गई है।
- `DITTO_STATE` को `"1"` पर सेट किया गया है।
- जीयूआई पुनः लोड होता है

### **2. डिट्टो मोड में**

- **किसी भी इनपुट पर (कीस्ट्रोक)**:
- DITTO मोड **स्वचालित रूप से बाहर निकल गया है** (`DITTO_STATE='0'`)।
- जीयूआई पुनः लोड होता है
- खोज फ़ील्ड **खाली** रहती है ('SAVED_QUERY' की कोई बहाली नहीं)।

### **3. DITTO से स्विच करना → पूर्ण-पाठ (`Alt+G` फिर से)**

- **कार्रवाई**:
- `DITTO_STATE` ``0'' पर सेट है।
- जीयूआई पुनः लोड होता है
- `SAVED_QUERY` **पुनर्स्थापित** है। (यह चरण इस समय काम नहीं करता 11.8.'26 22:18 मंगल)
