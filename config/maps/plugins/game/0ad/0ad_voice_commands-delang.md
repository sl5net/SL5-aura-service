# Sprachbefehle für 0 A.D.

Diese Anleitung listet alle verfügbaren Sprachbefehle für 0 A.D. auf. Sprich einen der genannten Beispielsätze, während 0 A.D. das aktive Fenster ist.


Anleitung der Sprachbefehle für deutsch-sprachige 0 A.D. Spieler
die folgendes Nutzen:

https://play0ad.com/
https://github.com/sl5net/autocivp

sehr zu empfehlen!

https://gitlab.com/4trik/ModernGUI

(S, 30.7.'26 17:39 Thu)



## Kamera-Steuerung

| Sprich | Aktion |
|---|---|
| "kamera nach norden" | Kamera nach Norden bewegen |
| "kamera nach süden" | Kamera nach Süden bewegen |
| "kamera nach westen" | Kamera nach Westen bewegen |
| "kamera nach osten" | Kamera nach Osten bewegen |

## Signal

| Sprich | Aktion |
|---|---|
| "alarm" | Alarm-Signal auslösen |

## 0 A.D. starten

| Sprich | Aktion |
|---|---|
| "0ad configuration" | 0 A.D. Konfiguration öffnen |
| "0ad mods" | 0 A.D. Mods öffnen |
| "0ad AppImage" | 0 A.D. AppImage starten |

## Einheiten bewegen

| Sprich | Aktion |
|---|---|
| "nach norden" | Ausgewählte Einheiten nach Norden bewegen |
| "nach süden" | Ausgewählte Einheiten nach Süden bewegen |
| "nach osten" | Ausgewählte Einheiten nach Osten bewegen |
| "nach westen" | Ausgewählte Einheiten nach Westen bewegen |
| "nach nordosten" | Ausgewählte Einheiten nach Nordosten bewegen |
| "nach nordwesten" | Ausgewählte Einheiten nach Nordwesten bewegen |
| "nach südosten" | Ausgewählte Einheiten nach Südosten bewegen |
| "nach südwesten" | Ausgewählte Einheiten nach Südwesten bewegen |

## Einheiten auswählen

| Sprich | Aktion |
|---|---|
| "alles markieren" | Alle eigenen Einheiten auswählen (Ctrl+Alt) |
| "wounded" | Verwundete Einheiten auswählen |

## Gebäude / Bauen

| Sprich | Aktion |
|---|---|
| "baue Haus" | Haus bauen |
| "baue feld" | Feld anlegen (Bauern pflanzen automatisch, Ernte nach ca. 8 Sekunden) |
| "acker pflanzen" | Feld anlegen (Alternative zu "baue feld") |
| "getreide pflanzen" | Feld anlegen (empfohlen — beste Erkennungsrate) |
| "baue Lagerhaus" | Lagerhaus bauen |
| "baue Baracke" | Baracke bauen |
| "baue farms" | Farm/Bauernhof bauen |
| "baue festung" | Festung bauen |

## Rohstoffe sammeln

| Sprich | Aktion |
|---|---|
| "holz" | Holz sammeln |
| "früchte" | Früchte sammeln |
| "fleisch" | Fleisch sammeln (Jagd) |
| "stein" | Stein sammeln |
| "metal" | Metall sammeln |

## Noch nicht vollständig auf Deutsch verfügbar

Diese Befehle funktionieren aktuell nur mit englischen oder gemischten Begriffen. Eine deutsche Übersetzung ist noch nicht implementiert.

| Sprich (aktuell) | Aktion |
|---|---|
| "wähle iddle" | Untätige Einheit auswählen |
| "seltext woman" | Weibliche Einheit auswählen |
| "wähle house" | Haus auswählen |
| "wähle markt" | Markt auswählen |
| "control barack" | Baracke steuern/auswählen |
| "farm" | Farm/Bauernhof auswählen |
| "control Storehouse" | Lagerhaus steuern/auswählen |
| "control alles" | Alle Gebäude steuern/auswählen |
| "wähle woman" | Weibliche Einheiten-Gruppe (Alt-Taste) |
| "wähle infantry" | Infanterie-Gruppe (Alt-Taste) |
| "wähle Spearman" | Speerträger-Gruppe (Alt-Taste) |
| "wähle Cavalry" | Kavallerie-Gruppe (Alt-Taste) |
| "wähle slinger" | Schleuderer-Gruppe (Alt-Taste) |
| "wähle Swordman" | Schwertkämpfer-Gruppe (Alt-Taste) |
| "wähle elephant" | Elefanten-Gruppe (Alt-Taste) |
| "wähle katapult" | Katapult-Gruppe (Alt-Taste) |
| "wähle heiler" | Heiler-Gruppe (Alt-Taste) |
| "nowoundedonly" | Nur nicht-verwundete Einheiten auswählen |
| "wähle d dangerous elephants" | Gefährliche Elefanten-Gruppe (Alt-Taste) |
| "wähle v siege" | Belagerungswaffen-Gruppe (Alt-Taste) |
| "wähle military" | Militär-Gruppe (Alt-Taste) |
| "wähle n nicht militar" / "alt n non military" | Nicht-militärische Gruppe (Alt-Taste) |
| "baue hause" | Haus bauen (alternative Schreibweise) |
| "build markt" | Markt bauen |

*Hinweis: Diese Liste basiert auf den `# EXAMPLE:`-Kommentaren im Quellcode unter `config/maps/plugins/game/0ad/`. Manche Formulierungen erkennt die Spracherkennung besser als andere — bei Problemen einfach ein anderes Beispielwort aus der Tabelle probieren.*
